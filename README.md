# 🏠 House Sales Analysis Dashboard

## Project Overview
Interactive Tableau dashboard to analyze house sales data and identify price trends, location-based insights, and property features impact.

## Tools Used
- Tableau
- Data Analysis
- Data Visualization

## Key Insights
- House price trends by location
- Effect of bedrooms, bathrooms, and area on price
- Time-based sales analysis

## Files
- House Sales Analysis Dashboard 12.twbx

## How to Use
Download the file and open it using Tableau Desktop.
